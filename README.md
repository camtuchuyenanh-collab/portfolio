# Bui Thi Cam Tu — personal website

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript. The `assets` folder contains the two school logos and the CV PDF, shown in the CV section and available to open or download.

## Preview locally

Open `index.html` in a browser. For a local web server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository for the website and add `index.html`, `styles.css`, `script.js`, `README.md`, and the complete `assets` folder. Keep the folder and filenames unchanged so the logos and CV link work.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the published address in the Pages settings when deployment finishes.

## Before publishing

The page displays the email address and phone number you provided and links to the CV PDF in `assets`. GitHub Pages makes repository content public, so check that the CV is the version you want to share before publishing.

## Customise

- Edit the content and page title in `index.html`.
- Change colours, spacing, and typography in `styles.css`.
- Theme preference is saved in the visitor's browser. Search opens with `/` or `Ctrl/⌘ + K`.
